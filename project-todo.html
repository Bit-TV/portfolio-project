Todo List App

An interactive task management app designed to help users organize their day by adding, editing, and checking off tasks. Built entirely with HTML, CSS, and JavaScript.

Key Features

  • Add and delete tasks
  • Mark tasks as completed
  • Persist data using localStorage
  • Responsive layout

Technologies Used

  • HTML5
  • CSS3
  • Vanilla JavaScript
  • localStorage API

Challenges Faced

Getting data to persist across sessions and handling dynamic DOM manipulation with event listeners was a rewarding challenge. I learned to better structure JavaScript functions.

What I Learned

This project solidified my understanding of interactive DOM elements, JavaScript array methods, and using browser storage effectively.
