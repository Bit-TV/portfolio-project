Portfolio Website

This portfolio was built to showcase my web development skills and artistic interests. It includes sections for my background, featured projects, skills, and contact information.

Design Goals

  • Clean, playful, and responsive layout
  • Personal branding through fonts, color, and content
  • Interactive features like smooth scrolling and a contact form

Technologies Used

  • HTML5 & CSS3
  • JavaScript
  • Google Fonts
  • GitHub Pages (deployment)

Challenges Faced

Making the layout responsive across all devices required testing and careful use of Flexbox. I also had to troubleshoot GitHub Pages pathing issues to ensure everything rendered properly.

What I Learned

This project taught me how to design a portfolio from scratch, structure a multi-page site, write cleaner semantic HTML, and publish work live online.
